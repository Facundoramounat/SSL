# SSL - Sintaxis y Semántica de Lenguajes
Este repositorio contiene los trabajos prácticos y ejercicios de la materia.

## Conceptos Aplicados - Tp 0
* **Redirección de Salida:** Uso de `freopen` para desviar el flujo de datos hacia archivos externos.
* **Automatización:** Configuración de un `Makefile` multiplataforma (Windows/Linux) para un flujo ágil de compilación y ejecución.
* **Estándares Modernos:** Desarrollo basado en el estándar **C23**.
